# Data Professional Survey Analysis – Power BI

## Project Overview

This project analyzes survey data from 630 data professionals using Microsoft Power BI. The analysis explores job roles, salaries, programming language preferences, work-life balance, salary satisfaction, and the difficulty of entering the data field.

## Objectives

- Analyze the distribution of survey participants by country
- Compare average salaries across data-related job titles
- Explore favorite programming languages
- Analyze the perceived difficulty of entering the data field
- Examine satisfaction with work-life balance and salary
- Explore characteristics of data professionals

## Dataset

The dataset contains 630 survey responses and 28 fields covering information such as:

- Job title
- Yearly salary
- Industry
- Favorite programming language
- Work-life balance satisfaction
- Salary satisfaction
- Difficulty entering the data field
- Age
- Country
- Education
- Other demographic information

## Dashboard Analysis

The Power BI dashboard includes:

- Total number of survey takers
- Average age of survey takers
- Average salary by job title
- Survey takers by country
- Favorite programming languages
- Difficulty of breaking into data
- Happiness with work-life balance
- Happiness with salary

## Key Metrics

- **630** total survey takers
- **29.87** average age of survey takers
- **5.74 / 10** average work-life balance satisfaction
- **4.27 / 10** average salary satisfaction
